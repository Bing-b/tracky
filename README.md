# Tracky

用于 Bug 复现与排查的浏览器扩展。录制网页 DOM 操作序列与 Console 报错，并导出为自包含的单文件 HTML 复现报告。

![Tracky 预览](example.png)

## 功能特点

- **DOM 录制与回放**：基于 rrweb 记录 DOM 变异序列，导出单文件 HTML 报告，清晰还原真实渲染且体积小（通常仅几百 KB）。
- **控制台异常捕获**：自动记录 `console.error`、`console.warn`、`window.onerror` 及未捕获的 Promise 异常。
- **报错与回放联动**：报告内嵌控制台，点击任意报错可直接跳转到对应时刻的回放画面。
- **敏感数据脱敏**：密码字段及表单输入默认脱敏，防止隐私泄露。
- **关键帧标记**：录制过程中可快速打点，在时间线上生成锚点以便定位。

## 快捷键

| 快捷键    | 功能                           |
| :-------- | :----------------------------- |
| `Alt + R` | 开始 / 停止录制                |
| `Alt + M` | 标记关键帧（时间线打点）       |
| `Alt + E` | 导出 HTML 复现报告与 JSON 数据 |

## 安装与使用

适用于 Chrome、Edge 等 Chromium 内核浏览器：

1. 下载代码或直接解压插件包；
2. 在浏览器地址栏访问 `chrome://extensions`（Edge 访问 `edge://extensions`）；
3. 开启右上角的 **开发者模式** 开关；
4. 点击左上角 **加载已解压的扩展程序**，选择 `tracky` 目录即可；
5. 访问任意网页即可开始使用，也可直接在浏览器中打开 `demo.html` 进行测试。
